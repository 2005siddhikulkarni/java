## ▶️ How to Run the Programs

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the repository directory**

```bash
cd YOUR_REPOSITORY_NAME
```

**3. Compile a Java program**

```bash
javac HelloWorld.java
```

**4. Run the compiled program**

```bash
java HelloWorld
```

Replace `HelloWorld.java` with your Java source file name. The class name must match the file name when the class is declared `public`.

Make sure the JDK is installed and configured on your system.
